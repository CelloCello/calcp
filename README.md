# 加減法練習器

這是一個幫助小朋友練習加減法的互動式網頁應用程式。採用可愛友善的界面設計，提供隨機出題、計時和成績統計功能。

## 功能特色

- 隨機生成加減法題目
- 支援三種練習模式：加法模式、減法模式和混合模式
- 支援兩種難度：10以內加減法和兩位數加減法
- 進階模式：除了標準題型外，還有求解未知數的題型
- 可自訂練習題目數量
- 自動計時，記錄完成時間
- 計算答題正確率
- 歷史記錄功能，可追蹤練習進度和表現趨勢
- 完全響應式設計，支援手機、平板和電腦
- 可愛友善的介面，適合小朋友使用

## 如何使用

1. 使用瀏覽器開啟 `index.html` 檔案
2. 在首頁選擇遊戲模式、難度、題目數量和是否開啟進階模式
3. 點擊「開始練習」按鈕開始遊戲
4. 看到題目後在輸入框中輸入答案
5. 按下「確認」按鈕或按 Enter 鍵提交答案
6. 系統會立即顯示答案是否正確
7. 完成所有題目後，系統會顯示練習結果

## 練習模式

### 加法模式
練習加法運算，給出兩個數字，讓使用者計算和。例如：2 + 3 = ?

### 減法模式
練習減法運算，給出兩個數字，讓使用者計算差。例如：5 - 2 = ?

### 混合模式
隨機出現加法和減法題目，幫助小朋友靈活切換運算方式。

## 難度設定

### 10以內加減法
加數、減數和被加(減)數都不會超過 10，適合初學者。

### 兩位數加減法
加數、減數和被加(減)數可能為一位數或兩位數，提供更具挑戰性的練習。

## 進階模式

當開啟進階模式時，除了標準題型外，還隨機出現需要求解未知數的題型，如：
- 2 + ? = 5（求解第二個數字）
- ? + 3 = 5（求解第一個數字）

這種模式能幫助小朋友更加靈活地理解加減法概念，並為日後學習代數打下基礎。

## 技術說明

這個應用程式使用純前端技術開發，包括：

- HTML5
- CSS3 (含 RWD 響應式設計)
- JavaScript (ES6+)

不需要伺服器或特殊設定，直接在瀏覽器中開啟 HTML 檔案即可使用。
